# SINDAENG IP Proposal — Volume 1

Status: In development  
Version: 1.0  
Working branch: `codex/sindaeng-ip-proposal-v1`

## Purpose

Create a presentation-ready IP proposal for SINDAENG, positioned as a Korean emotional designer-toy brand.

## Core Brand Statement

**Emotion grows on the head.**

SINDAENG does not hide emotions. Each feeling appears as an evolving visual ecosystem called an **Emotion Bloom™**, connecting character design, story, animation, art toys, goods, and licensing.

## Deliverables

- Volume 1 proposal structure and copy
- Page-by-page visual direction
- Emotion System™ and Bloom Code™
- Character DNA and world-building framework
- Art-toy and merchandise strategy
- Short-form animation strategy
- Licensing and business roadmap
- Rights-protection checklist
- Export-ready DOCX/PDF/PPTX specifications

## Initial Production Order

1. Page 01 — Cover / Brand Statement
2. Page 02 — Why SINDAENG?
3. Page 03 — Brand Philosophy
4. Page 04–05 — Emotion System™
5. Page 06 — Character DNA
6. Page 07–09 — Official Character & Visual Language
7. Page 10 onward — World, products, content, licensing, roadmap

## Source Assets

The current project uses the approved SINDAENG character sheets, turnarounds, expressions, poses, and product-concept images supplied in the project conversation. Original high-resolution assets should be collected in a dedicated `/assets` directory before final export.
